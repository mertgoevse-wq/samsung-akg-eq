## Richtlinien
- Bilddateien dienen ausschließlich als ästhetische Orientierung und Designreferenz.
- Sie ersetzen nicht die echtzeitfähige, native Jetpack-Compose-Canvas-Partikel-Engine (`ParticleField.kt`).
- Für verlässliche Generierung ohne anonymer Rate-Limits kann der Nutzer sich über `claude-media-bridge login` mit Google autorisieren (Nano Banana 2).
